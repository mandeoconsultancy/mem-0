# mem-0

A persistent, compounding personal knowledge base inspired by Andrej Karpathy's LLM Wiki concept.

## Structure

- `CLAUDE.md` — operating instructions
- `raw/` — immutable source material
- `wiki/` — compiled, interconnected knowledge

## Operating modes

- **INGEST** — compile new source material into the wiki
- **QUERY** — answer from the compiled wiki first
- **LINT** — audit wiki health
- **RESEARCH** — research, ingest, and synthesize
- **SAVE** — persist durable knowledge

The wiki is designed to remain portable across AI systems and tools.
